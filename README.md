# TomTroc 📚

Plateforme d'échange de livres entre particuliers : bibliothèque personnelle,
recherche de livres et messagerie entre membres.

Projet du parcours **Développeur d'application PHP/Symfony** (OpenClassrooms) —
PHP natif, architecture MVC, sans framework.

## Installation

1. Copier le projet dans `htdocs` de [MAMP](https://www.mamp.info/), dans un sous-dossier `TomTroc`.
2. Créer une base `tom_troc` dans phpMyAdmin et importer `tom_troc.sql`.
3. Adapter si besoin les identifiants MySQL dans `Utils/Database.php` (défaut : `root` / `root`).
4. 4. Ouvrir `http://localhost:8888/TomTroc/index.php` (adapter le port à votre configuration MAMP).
